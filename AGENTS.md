# AGENTS.md

Инструкции для любого ИИ-агента (Claude, Codex и др.), работающего в этом репозитории.

Проект — Android-приложение в `android_app/`. Python-прототип удалён.

Прежде чем что-либо делать, прочитай:

1. `docs/STAGE_RULES.md` — как работать, коммитить и отчитываться;
2. `docs/ARCHITECTURE.md` — структура, инварианты, эталон озвучки, журнал решений;
3. `docs/PLAN.md` — этапы и их статус;
4. свой бриф в `docs/stages/`, если ты исполнитель этапа.

Главное в одну строку: делай только свой бриф, мелкими коммитами в `master` с префиксом
`[SNN]` и сразу `git push`; ключи (`credentials.properties`) не читай вслух, не печатай
и не коммить.
