# Listening Comprehension Trainer

Android-приложение для тренировки понимания английской речи на слух.
Ученик разговаривает голосом с учителем; речь учителя делится на короткие
смысловые группы с паузами, чтобы слитную речь было легче разбирать.

Приложение работает через API OpenAI: распознавание речи, ответ учителя, озвучка.
Ключ OpenAI вводит пользователь на первом экране; ключ хранится только на устройстве.

## Как собрать

Нужны:

- JDK 17 или новее (сборка проверена на JDK 21);
- Android SDK: `platforms;android-34` и `build-tools;34.0.0`.

**Android Studio.** Открой каталог `android_app/` как проект и запусти конфигурацию `app`.

**Командная строка.**

```bash
cd android_app
export ANDROID_HOME=/путь/к/Android/Sdk   # или файл local.properties со строкой sdk.dir=/путь/к/Android/Sdk
./gradlew assembleDebug
```

Готовый APK: `android_app/app/build/outputs/apk/debug/app-debug.apk`.
Установка на подключённый телефон:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Gradle отдельно ставить не нужно: `./gradlew` сам скачает нужную версию (8.7).
Файл `local.properties` в репозиторий не попадает.

## Первый запуск

1. Введи ключ OpenAI и нажми «Validate Key».
2. Нажми «Start Listening Practice».
3. Разреши доступ к микрофону, когда приложение спросит.

Пользоваться приложением нужно в наушниках.

## Как устроена работа над проектом

Архитектуру и план ведёт один чат-архитектор, каждый этап выполняет отдельный
чат-исполнитель. Всё, что нужно знать о проекте, лежит в `docs/`; начинать чтение
стоит с `docs/ARCHITECTURE.md` и `docs/PLAN.md`.

Прежний прототип на Python (CLI) удалён из репозитория и остался только в истории git.
