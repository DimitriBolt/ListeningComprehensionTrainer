# S03d — потоковое распознавание кодом приложения на записях S03b

_Прогон: 2026-11-26, 48 записей (последний дубль каждой реплики), 8.1 мин звука, 2 мин 33 с; цена ≈ $0.157 (поток $0.125 по `usage`, файл ≈ $0.032 по длине)._

Код приложения: `RealtimeTranscriber` (`gpt-live-transcribe`, `delay: low`, `prompt` = `TranscriptionPrompt.CONTEXT`), 4 сессии по 12 записей подряд, звук в темпе реального времени кусками 80 мс, конец — `VadTurnDetector` + `SileroVad` (3000 мс тишины после речи) или кнопка, `commit` при речи, ожидание текста ≤ 2500 мс, иначе файл. Файл для сравнения — `FileTranscriber` (`gpt-transcribe`, WAV до того же конца, тот же `prompt`). Точность — доля слов сценария, найденных при выравнивании (как `accuracy` пробы S03b, «um» не считается).

Ложный конец на паузе обдумывания (D65) запись **не** останавливал: она шла до первого конца после конца речи по разметке S03b. Таких пауз было 23 (в 23 записях).
