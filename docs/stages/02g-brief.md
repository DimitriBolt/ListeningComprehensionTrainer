## Зачем этап

**Что получилось после S02e–S02f.** Учитель стал собеседником: поправка первой, вопрос в конце, без
лекций. Но пользователь пишет: «Мы переборщили с краткостью». Собственный текст учителя без поправки —
5–11 слов, например «Hello! What do you like?». Из такой реплики почти нечего услышать и понять. Вопрос
к ней получается странным: его не к чему привязать.

**Новые правила (раздел «Методика»):**
- **D51.** Реплика содержательна:
  - на старте — 3–4 простые фразы, ≈ 25–40 слов своего текста;
  - длиннее, когда ученик уверенно понимает;
  - короче, когда не понял.
- **D52.** Вопрос растёт из сказанного. Типы чередуются:
  - проверка понимания — ответ есть в только что сказанном;
  - личный вопрос, связанный со сказанным.

**Что остаётся как было:**
- реплика кончается первым вопросом (D48);
- поправщик (D53);
- русское слово по счёту (D55);
- «сначала уточни» для неоднозначных просьб.

## Что сделать

### 1. Промпт учителя

Переписать правила длины и вопроса в `tutor_prompt.txt`. Остальное — без изменений.

- **Длина (D51).**
  - На старте: 3–4 фразы, 25–40 слов своего текста.
  - Ученик отвечает уверенно и правильно: постепенно длиннее, до ≈ 60 слов (5–6 фраз).
  - После «не понял» (служебная строка D55 или явные признаки): 1–2 фразы, проще.
  - Каждая фраза короткая и простая, обычно ≤ 10 слов. Уровень слов и времён — по D42, как сейчас.
- **Содержание.** До вопроса — настоящее содержание по теме ученика:
  - ответ с одной-двумя деталями;
  - пример;
  - маленький факт;
  - короткая история («Many people in Tucson…»).

  Не пересказывать слова ученика вместо содержания.
- **Вопрос (D52).**
  - Ровно один, в конце.
  - Вопросов посреди реплики нет, в том числе риторических («Do you know? …»): D48 обрежет реплику на
    таком вопросе.
  - Типы чередуются: проверка понимания (ответ — в только что сказанном) и личный вопрос, связанный со
    сказанным.
  - Вопрос, на который можно ответить, не слушая реплику, — плохой вопрос.
- **Уточнение.** Реплика с уточняющим вопросом (неоднозначная просьба, большая тема) может быть короче:
  - одна фраза о теме — без цифр, дат и имён;
  - затем вопрос с выбором.

  Не голый вопрос. Пример: «Arizona has a long and interesting history. Do you want old times or new
  times?»
- **Поиск.** Убрать лишний поиск на общих знаниях. В S02f на шаге 2 сценария S5 («The old times,
  please.») учитель искал в 4 случаях из 6. История, география, наука и известные люди — без поиска.
- **`max_output_tokens`.** Проверить предел 200 (D49) на новой длине вместе с поиском. Если в пробе
  есть обрезки, поднять (например, до 300) и записать причину.

### 2. Журнал

- В мере реплики добавить `own_words N` — слова учителя без поправки. Сейчас `words` считает всё вместе
  с поправкой, а норма D51 — про свой текст учителя.

### 3. Повтор `tutor-dialog`

- **Сценарии.** Прежние S1–S6, плюс новый S7.
  - S7 — разговор о питомце: ученик даёт короткие сведения («I have a dog.», «His name is Max.»,
    «He is five.», «He likes to run.»).
  - Ожидание для S7: учитель каждый раз добавляет содержание (деталь, пример), вопросы чередуются.
- **Новые меры** — по каждой реплике и сводкой:
  - `own_words` (медиана, максимум), самая длинная фраза;
  - тип вопроса: проверка понимания, личный, уточняющий, другой;
  - вопрос связан со сказанным (да/нет);
  - есть ли содержание (факт, деталь, пример).

  Тип вопроса, связь и содержание размечает модель-судья: `gpt-6-luna`, отдельный короткий промпт. 20
  разметок проверь сам и напиши в отчёте, сколько совпало.
- **Цели** (итоговый прогон, 3 повтора):

  | Мера | Цель |
  |---|---|
  | `own_words` в обычных репликах (не уточнение, не после «не понял»): медиана | 25–40 |
  | `own_words`: максимум | ≤ 60 |
  | после «не понял» (S3 шаги 2–4, S6) | ≤ 20 слов |
  | самая длинная фраза: медиана / максимум | ≤ 10 / ≤ 14 слов |
  | S4 (уверенные ответы): шаг 4 длиннее шага 1 | в 2 из 3 повторов |
  | вопрос в конце | ≥ 90 % |
  | вопрос связан со сказанным | ≥ 90 % |
  | содержание в обычных репликах | ≥ 90 % |
  | среди обычных вопросов проверка понимания и личные | каждого типа ≥ 25 % |

  Прежние цели S02f сохраняются:
  - поправки S1–S2 — 12 из 12, ложных — 0;
  - русское слово только в S3 на шаге 4;
  - S5 шаг 1 — вопрос с выбором, без фактов, дат, имён и поиска.

  Новая цель: в S5 нет поиска ни на одном шаге. Обрезок пределом длины — 0.
- **Доводка:** до 3 правок промпта, все прогоны сохранить в `docs/research/02g-dialogs.md`. Бюджет — до
  $1, подтверждение перед запуском.
