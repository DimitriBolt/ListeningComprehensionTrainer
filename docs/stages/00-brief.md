# Бриф S00 — Разведка и уборка

Стартовая фраза для нового чата:

> Ты исполнитель этапа S00 проекта github.com/DimitriBolt/ListeningComprehensionTrainer.
> Прочитай в репозитории `docs/STAGE_RULES.md`, `docs/ARCHITECTURE.md`, `docs/PLAN.md`
> и `docs/stages/00-brief.md` и выполни задание из брифа.

## Зачем этап

OpenAI отключает модели, на которых работает приложение (сроки — в
`docs/ARCHITECTURE.md`). Архитектору нужно решение D4: переходить на Realtime API
или обойтись минимальной заменой. Для решения нужны проверенные факты, а не память.

Код приложения на этом этапе **не меняется**.

## Часть 1. Разведка

Результат: файл `docs/research/00-models.md`. Каждое утверждение — со ссылкой на
официальную документацию OpenAI и датой, когда ты её читал. Что не удалось
подтвердить официальным источником, пометь «не подтверждено».

Ответь на вопросы.

**Текст (сейчас `gpt-4o-mini`, `/v1/chat/completions`, function calling)**
1. Отключают ли `gpt-4o-mini`, когда, на что заменять?
2. Работает ли замена через тот же endpoint с теми же `tools`? Цена.

**Распознавание (сейчас `whisper-1`, загрузка WAV-файла)**
3. `gpt-transcribe`: работает ли через `/v1/audio/transcriptions` с загрузкой файла?
   Какие параметры изменились? Цена.
4. `gpt-live-transcribe`: как подключаться, есть ли промежуточные результаты,
   какие режимы определения конца реплики доступны в сессии транскрипции
   (`server_vad`, `semantic_vad`, параметр `eagerness`), цена.

**Синтез (сейчас `tts-1`, отдельный запрос на каждую смысловую группу)**
5. `gpt-realtime-2.1-mini`: может ли она произнести **заданный текст дословно**?
   Это главный вопрос: текст учителя мы готовим сами и режем на группы с паузами.
6. Управляется ли скорость речи? В каком формате приходит звук? Какова задержка
   до первого звука?
7. Остаётся ли у OpenAI какой-либо синтез речи вне Realtime API?
8. Запасные варианты синтеза, если дословное чтение невозможно: встроенный
   Android `TextToSpeech` и сторонние сервисы. Только перечень с плюсами и минусами.

**Realtime API в целом**
9. Как подключаться с Android: WebSocket или WebRTC? Можно ли использовать обычный
   ключ пользователя прямо с устройства?
10. Как устроено перебивание (`interrupt_response`) и `semantic_vad`.

**Сравнение вариантов**

| | A. Полный Realtime (речь → речь) | B. Прежний конвейер на новых моделях | C. Гибрид: вход через Realtime-транскрипцию, выход свой |
|---|---|---|---|
| Сохраняется ли принцип чанков и управление паузами | | | |
| Задержка до первого звука учителя | | | |
| Цена 10-минутного занятия | | | |
| Объём переписывания | | | |
| Что решается «бесплатно» (конец реплики, перебивание) | | | |

Заверши документ разделом «Рекомендация»: один вариант и три главные причины.
Решение примет архитектор.

## Часть 2. Уборка

1. Удали Python CLI: `main.py`, `src/`, `requirements.txt`, `.env.example`.
2. Перепиши `README.md`: проект — Android-приложение в `android_app/`; как собрать;
   ссылка на `docs/`.
3. Проверь `.gitignore`: в репозиторий не должны попадать `local.properties`,
   каталоги сборки, записи голоса, файлы с ключами.

## Часть 3. Проверка среды

Выясни и запиши в отчёт: можешь ли ты в своей среде собрать `android_app`
(`assembleDebug`) и запускать модульные тесты? Если нет — что именно мешает.
От этого зависит, как будут проверяться следующие этапы. В репозитории сейчас
нет Gradle wrapper; если можешь его добавить — добавь.

## За пределами этапа

- любые изменения Kotlin-кода;
- выбор варианта A/B/C за архитектора;
- проверки с настоящим ключом OpenAI.
