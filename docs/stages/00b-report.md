# Отчёт S00b — Пробы с ключом

## Сделано
- `tools/probe/probe.py` — один скрипт с подкомандами `verbatim`, `latency`, `voices`, `tutor`,
  `transcribe`, `vadservice`, `all`; справка на русском (`python probe.py -h`,
  `python probe.py <команда> -h`).
- Ключ читается из `credentials.properties` в корне (строка `APIkey=...`; путь меняется
  `--credentials`). Ключ не печатается и вырезается из всего, что пишется в файлы.
  На 401 выводится понятное сообщение без ключа, и прогон останавливается.
- Перед `all` скрипт печатает оценку стоимости (≈ $0.21 сверху) и ждёт `y`; `--yes`
  пропускает вопрос. У каждого запроса таймаут (`--timeout`, по умолчанию 45 с). Сбой
  одной пробы, а в `verbatim` — одной группы, пишется в результаты и не роняет прогон.
- Результаты: `tools/probe/out/results.md` + `out/results.json` + звук в `out/verbatim/`
  и `out/voices/`. Копия без путей к звуку — `docs/research/00b-results.md`, обновляется
  после каждой подкоманды. В конце скрипт печатает команду `git add … && git commit … && git push`.
- `fixtures/chunks.txt` — ровно 50 групп. Получены из `fixtures/teacher_replies.txt`
  (шесть типичных ответов учителя) функцией `split_into_chunks` — это **перенос**
  `TrainerViewModel.splitIntoChunks` на Python с сохранением его особенностей. Среди групп
  есть вопросы, повелительные фразы, обрывки из 1–2 слов (`and`, `then they`, `Repeat`),
  `What do you think?`, `Tell me more.`, `$3.29`, `November 16,`, `2026.`, `December 24th,`, `38 days`.
- Сравнение текста группы с расшифровкой: нормализуются регистр, пунктуация, кавычки,
  числа (цифрами и словами, годы как «twenty twenty six», даты как «sixteenth», `$`, `%`).
  Вердикты: дословно / только сокращения (`That's` = `That is`) / расхождение с перечнем
  различий / пусто / ошибка. Если расшифровка намного длиннее текста, она помечается
  «похоже на ответ».
- `tools/probe/README.md`: venv, установка, команды, время и цена по каждой пробе, что
  делать после прогона.
- `.gitignore`: `tools/probe/out/`, `tools/probe/.venv/`, `.pytest_cache/`.

## Замечено за пределами этапа
- **`splitIntoChunks` расходится с эталоном озвучки.** В `ARCHITECTURE.md` написано, что
  `1. **Заголовок**` — одна неразрывная группа. Перенос (то же регулярное выражение) даёт
  **две** группы: `1.` и `**Make**`, причём после `1.` пауза абзаца. Причина в `\s*` внутри
  `(?<!\d\.)\s*(\*\*.*?\*\*)`: совпадение начинается после пробела, и проверка «перед
  `**` нет `1.`» проходит. На устройстве не проверял: вывод сделан по переносу.
- Разрез «перед союзом» срабатывает и перед словами, которые лишь начинаются на союз:
  `ask` (as), `order`, `oranges` (or), `some`, `sorry` (so), `whole` (who), `afternoon` (after).
  Проверено на переносе: `I ask you` → `I` | `ask you`; `I am sorry` → `I am` | `sorry`;
  `the whole day` → `the` | `whole day`. Плюс `and then` распадается на `and` | `then they`, `Repeat after me.` — на `Repeat` | `after me.`.
- Деление пополам длинной группы режет внутри кавычек: `I think you meant "Yesterday` | `I went to the shop`.
- Realtime API с неверным ключом **не отклоняет** WebSocket при подключении: открывает его,
  а затем закрывает кодом 3000 с причиной `invalid_request_error.invalid_api_key`
  (проверено запросом 2026-11-16). Это нужно учесть в `Synthesizer` в S02.
- Ответ OpenAI на 401 содержит последние 4 символа ключа (`sk-proj-****…7890`). Если
  приложение где-то показывает текст ошибки целиком, это стоит учесть.
- Из документации, прочитанной сейчас, — снимает «не подтверждено» из S00:
  - multipart для `gpt-transcribe` в curl-примере гайда передаётся как `languages[]=en` `[STT]`;
  - гайд Realtime conversations прямо пишет, что можно генерировать несколько ответов
    **одновременно** (out-of-band, `conversation: "none"`) — это ответ на вопрос о
    параллельных запросах синтеза в одной сессии;
  - `conversation.item.input_audio_transcription.completed` несёт `usage` (токены или секунды).

  Проба всё равно проверяет это запросами.

## Вопросы к архитектору
- Порог «98 % дословных» считать по строгому вердикту или вместе со «только сокращения»
  (`That's` ↔ `That is` звучит одинаково, но расшифровка может раскрыть)? В результатах
  есть обе доли; автоматический запуск промпта 2 сейчас идёт по строгой.
- `response.create` принимает поле `reasoning` (справочник client events), но значения
  `effort` для `gpt-realtime-2.1-mini` в документации не названы. По умолчанию поле не
  передаётся. Если `latency` покажет долгий первый звук, можно повторить
  `python probe.py latency --rt-reasoning low` — стоит ли включить это в инструкцию пользователю?
- Расход «VAD как услуга» без ответов `response.done` не показывает. Его видно только в
  панели Usage, и в результатах оставлена строка, куда пользователь впишет цифру. Хватит ли этого?
